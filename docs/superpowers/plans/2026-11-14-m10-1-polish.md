# M10-1 Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the last 1.0 gaps before v1.0.0: a theme or desktop-app crash never strands the player (NFR-REL-2), the owner's three backlog items, the player-visible / data-risk M10 minors, and an NFR-OBS-1 test so every requirement traces to a test (NFR-MAINT-2).

**Architecture:** React error boundaries in the launcher renderer (front-end theme, each desktop window, the whole tree) report crashes to main over a new typed channel `app.reportError`, which writes them to the rotating log. Library data lives in main's SQLite, so containing the crash in the renderer is what keeps it safe. Backlog items extend existing contracts: `ScanSummary.missingLocations`, a pure overlap check in `packages/shared`, an `essentials` narrowing on game list/facets queries and an `essentialsOnly` import option. Minors are small fixes, each with a failing test where it is code.

**Tech Stack:** Electron 45, React 19, TanStack Query, Zod 4, better-sqlite3/Drizzle, vitest + Testing Library, Playwright (Electron), Fastify (API), GitHub Actions.

**Spec:** `docs/01-product/02-product-requirements.md` (NFR-REL-2, NFR-OBS-1, NFR-MAINT-2, FR-LIB-1/3/8, FR-IMP-1/2, FR-CAT-3, FR-SET-5/6, NFR-UPD-1), the owner's answers of 2026-11-14 (below), and the deferred minors in `.superpowers/sdd/2026-10-30-m10-release/progress.md` (gitignored ledger).

## Owner answers (2026-11-14)

- **Scan "folder not found":** after a scan, the summary names each storage location (drive/root folder) that wasn't found. Per-system subfolders that don't exist stay silent. The Catalog folder (managed location) is never reported: it doesn't exist until the first install.
- **"Catalog folder holds ROMs":** Settings → Storage warns when the Catalog folder is, is inside, or contains one of the user's own storage locations (installs/uninstalls would mix with their ROMs). A warning, not a validation error: saving still works.
- **"Essentials only" (D63), both parts:** (a) a scope-view filter "Essentials only" that shows only the games in any collection whose name is "Essentials" or ends in " Essentials" (case-insensitive); (b) an Import NextLevelOS option "Essentials collections only" that imports only those collections. Games, settings and menus import as before; menu nodes for collections not imported are dropped, and a folder left empty by that is dropped too.
- **D64 (this plan):** a portable folder copied to another PC gets its own sync device key: `settings.sync.deviceHost` records a hash of the PC's host name; a mismatch at sync time makes a new `deviceKey`. A copy keeps `sync.json`, so the old key's plays count as another PC's and nothing is counted twice.

- TDD: failing test first for logic, services, routes and components; test names carry the requirement ID (`NFR-REL-2: …`, `FR-LIB-3: …`, `D63: …`). Never commit failing or skipped tests.

- All user-visible strings via `t('…')`, with keys in both `packages/shared/src/i18n/en.json` and `pt-BR.json` (the locales test checks parity).

- Commit style: Conventional Commits, scopes `launcher`, `api`, `shared`, `ci`, `docs`; one commit per task.
- Local test runs: full vitest from PowerShell in `C:\` with `$env:CI=1; npx vitest run`; e2e with `ELECTRON_RUN_AS_NODE` unset (`Remove-Item Env:ELECTRON_RUN_AS_NODE -ErrorAction SilentlyContinue; npm run test:e2e -w apps/launcher`). Python edits: `PYTHONUTF8=1`.

## Review Focus

1. **A theme that throws on every render** (not once): Restart theme must not loop or freeze; the crash screen stays usable with a gamepad, and Switch theme / Back to desktop get the player out. → Task 1 test "a theme that keeps throwing shows the crash screen again after Restart theme".
2. **Locked kiosk with the desktop hidden when the theme crashes:** no Back to desktop button and no Switch theme if those are hidden; Restart theme is always there. → Task 1 test.
3. **A storage location on an unplugged drive:** its games go missing (FR-LIB-4, unchanged) and the summary says why; a location path that exists but holds no system folders is *not* reported. → Task 2 tests.
4. **Path comparisons on Windows:** `E:\Roms` vs `e:/roms/` vs `E:\Roms2` — overlap must be case- and slash-insensitive and must not treat a sibling prefix as inside. → Task 3 tests.
5. **Settings with `deviceHost` null** (every PC that synced on 1.0.0-beta.1): adopt the current host without changing the key, so an upgrade never splits a PC's play counter. → Task 5 test.
